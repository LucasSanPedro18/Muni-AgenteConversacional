# Muni-AgenteConversacional
Agente conversacional con LangChain y Gemini que orienta a vecinos de Rosario sobre trámites municipales: responde con RAG sobre páginas de rosario.gob.ar, calcula costos y reserva turnos aplicando reglas de negocio. Chroma + embeddings multilingües. TP de Inteligencia Artificial, UTN FRRO.
